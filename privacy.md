# Privacy Policy for Inkbeat Studio Tools

Last updated: November 25, 2026

Inkbeat Studio Tools is a private desktop helper that a single creator uses to manage their own YouTube channels. It is not offered to the public.

## What data the app accesses

When the channel owner signs in with Google, the app requests access to the YouTube Data API and the YouTube Analytics API. With that access it reads channel information, the list of uploaded videos and their details, and channel analytics such as views and watch time. It can also edit video details (title, description, tags, category, privacy and schedule), upload videos and thumbnails, and delete videos when the owner asks it to.

## How the data is used

The data is only used to show the owner information about their own channels and to make the changes the owner requests. It is not used for advertising, profiling or any other purpose.

## How the data is stored

The Google sign-in token is stored only on the owner's own computer so the app can stay signed in. Channel and video data is fetched when needed and is not kept on any server. The app has no server and no database.

## Sharing

The app does not sell, share or transfer any Google user data to anyone.

## Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Removing access

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Deleting the token file on the computer also removes the app's stored access.

## Contact

Questions about this policy can be raised as an issue at [github.com/Kaysan-arc/studio-tools](https://github.com/Kaysan-arc/studio-tools/issues).
