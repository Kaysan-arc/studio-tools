# Inkbeat Studio Tools

Inkbeat Studio Tools is a private desktop helper that a single creator uses to manage their own YouTube channels.

It uses the YouTube Data API and the YouTube Analytics API to list uploaded videos, edit video titles, descriptions, tags, categories, privacy and scheduling, upload videos and thumbnails, and read channel analytics. It only works on channels whose owner has signed in with Google and granted access.

The app is not offered to the public and has no user accounts of its own.
